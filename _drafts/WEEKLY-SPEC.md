# WEEKLY-SPEC.md — 市場週報生成規格

給任何生成週報草稿的 agent(Cowork 排程任務、Claude Code、對話中的 Claude)。生成前請完整讀完本檔。

## 目的與定位

「市場週報」是投資筆記底下的週更系列。它不是新聞彙整:媒體報「發生了什麼」,週報報「這些事怎麼串起來、怎麼推演、上次推演對不對」。核心價值在第三段(主軸)和第四段(檢核 + 觀察清單),這兩段最終由 Francis 定稿,agent 只提供底稿。

## 檔名、路徑與母版

- 正式檔:`weekly/2026-wNN.html`(NN = ISO 週數,兩位數)。
- 草稿檔:`_drafts/weekly/2026-wNN.html`。**草稿不 commit**(`_drafts/weekly/` 已列入 .gitignore);發佈時由「發佈週報」程序搬入 `weekly/` 才進版本庫。
- 母版:`weekly/` 目錄下**最新的一期**(創刊母版為 `weekly/2026-w31.html`)。複製整個檔案後逐段替換內容,不動 `<style>` 與深色區塊。
- 每期要改:`<title>`、canonical、hero(h1 + sub 期別日期)、`.asof` 時效聲明日期、`.tldr`、`.numstrip`、時間軸表格、`.aside` 數據備註、主軸段、檢核段、觀察清單、資料來源、`.pager`。

## 標題慣例

- `<title>` 與 rss title:`市場週報 WNN｜<主軸句>`(例:市場週報 W31｜獎勵 AI 收入、懲罰 AI 支出)。
- hero h1 只放主軸句;sub 固定格式:`2026 WNN · MM.DD – MM.DD`,有特殊主題可加(如「超級財報週」)。

## 五段架構(順序固定,不增段)

### 1. 本週一句話(.tldr)+ 關鍵數字列(.numstrip)
- 兩到三句講完本週市場邏輯,不是事件清單。
- numstrip 固定四格:標普 500、那斯達克 100、台股加權、台積電 2330。各附收盤值與週漲跌;若當週有極端單日行情可併註(如「週 −1.2%｜五 +8%」)。

### 2. 一週時間軸(.framework 表格)
- 五個交易日一日一列:日期 / 美股 / 台股 / 當日一件事。
- **每天只留一件事**,從當週每日收盤報告壓縮而來。取捨是這段的價值,不是完整。
- 表格下方 `.aside` 放數據備註(基準日、月線數字、紀錄級描述的保留聲明)。

### 3. 本週主軸(唯一的分析段)
- **只挑一個命題**,400–600 字。想寫第二個命題的素材,留給下期或獨立長文。
- 結構:一句話點出分界線或機制 → 用本週的具體數字與事件展開 → 收在保留條件或未解的問題,不收在篤定結論。
- 這段是給 Francis 改寫的底稿。寫完在段落開頭加 HTML 註解:`<!-- DRAFT: 主軸段為底稿,待 Francis 改寫定稿 -->`。

### 4. 上週檢核(.checkrow)+ 下週觀察清單(.watch)
- 檢核:讀上一期(`weekly/` 最新一期)的 `.watch` 每一條,逐條產生一個 `.checkrow` li。`.verdict` 標記:`命中` / `未觸發` / `相反` / `待定`,後接一行本週落點證據。判定不確定的標 `待定` 並註明缺什麼資料,不要硬判。
- 觀察清單:3–5 條,**每條是可檢驗的條件句**(「若 X 則 Y」),不寫「留意風險」這種永遠不會錯的話。每條開頭 `.cue` 粗體標觀察對象。
- 這兩段同樣是底稿,同樣加 `<!-- DRAFT -->` 註解。

### 5. 資料來源(.sources)+ 免責(.foot 內建)
- 來源分類列出:行情、財報、央行/殖利率、台股統計。標明日期區間。

## 資料紀律(最重要的一節)

- 所有數字以當週每日收盤報告與本週總結為唯一來源;報告裡沒有的數字**不要生成**,寧缺勿造。
- 「史上第 N 大」「史上最大」「數十年高點」等紀錄級宣稱:**不進主文**,集中放在 `.aside` 並聲明「以官方統計為準」;經 Francis 查證確認後才可寫回主文。
- 不確定的數據用條件式寫法(「約」「附近」)或移入 `.aside`,不要斷言。
- 週漲跌的計算基準(上週五收盤)在 `.aside` 註明。

## 語氣與風格

- 白話、分析性、機制導向;比喻要落在機制上(參考股癌式寫法),不說教、不喊單。
- 普遍傾向用「我們」,不用「你」指著讀者。
- 無 emoji;主文不用條列(觀察清單的 .watch 是元件,不算);投資筆記可用破折號。
- 主軸段允許一句 `.hl` 重點底線、至多一處 `.pull` 金句;用不到就不用。

## 技術檢查(生成時自檢)

- `<head>` 含 GA 標籤(G-HR79WVR1T3)。
- canonical = `https://francpeng-ops.github.io/francis-notes/weekly/2026-wNN.html`。
- HTML 內的角括號一律轉義(`&lt;` `&gt;`)。
- 不動 `<style>`;新內容只用既有元件(.tldr / .numstrip / .framework / .aside / .checkrow / .watch / .pull / .hl / .sources / .pager)。
- `.pager` 加 prev 指向上一期(上一期的 next 由發佈程序補)。
